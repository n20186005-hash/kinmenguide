## 初訪先選一個主題
烈嶼不只有九宮坑道。南岸看岬角、漁港與夕照，西北岸有戰史、營區和岩石地景，東林與后頭則適合聚落、親子和信仰散步。以下分區收錄34個景點與參訪資訊點；其中開放待確認的虎堡及L56只提供辨認與查詢提醒，不代表全部都可隨時入內。

半天留給九宮周邊與午餐；第一次環島可選[一日路線](/itineraries/lieyu-one-day/)的五六站。喜歡騎行可先讀[金門自行車旅行指南](/guides/kinmen-cycling/)，再從[烈嶼單車一日遊](/itineraries/lieyu-cycling-one-day/)刪減適合自己的站點。若對營區、古井或民俗有興趣，參考[兩天慢遊](/itineraries/lieyu-two-days/)，每半天保留交通和休息空間。

| 景點 | 怎麼選 |
| --- | --- |
| [九宮坑道](/attractions/jiugong-tunnel/) | 地下水道與運補歷史，初訪預留60–90分鐘。 |
| [四維七營區](/attractions/siwei-seventh-camp/) | 舊營區活化，參訪範圍、餐飲及體驗時間分別確認。 |
| [人文風雞](/attractions/lieyu-wind-rooster/) | 九宮碼頭旁的入口地標，與西方北風爺旁的風雞不同。 |
| [羅厝媽祖公園](/attractions/luocuo-mazu-park/) | 山上媽祖像與港灣視角，需走坡道和階梯。 |
| [東林東井](/attractions/donglin-east-well/) | 宋代古井，從保護設施外側閱讀聚落歷史。 |
| [習山湖公園](/attractions/xishan-lake-park/) | 親子遊具；水景、年齡與身高限制依現場。 |

## 選交通，也選適合同行者的步調
從本島可依[金門到烈嶼交通指南](/transport/kinmen-to-lieyu/)規劃跨橋；公車旅人先確認班次與回程，不能直接照自駕時間表走。帶幼童可把坑道或營區換成習山湖、文化館；行動不便者先問館方動線，海岸與地下工事常有階梯或不平地面。

住宿在本島可當天往返，想留在烈嶼則先問業者用餐、停車與接送安排。不要把最後一處偏遠海岸排在搭機前：跨橋、還車、接送和航空公司報到期限都需要獨立留時間。

## 風雨天與入夜後的取捨
大風縮短岬角、平台和山頂停留；雨天先查文化館與戰史館是否開館。舊營區、潮間帶與無照明路段不要摸黑探路。精確座標未核實的點使用地名查詢，地圖搜尋結果仍需對照官方或現場入口。

## 吃飯也按區域安排

用[烈嶼午餐與芋頭冰指南](/food/lieyu-food/)選一份正餐和需要的點心，先看各店營業時段，再安排景點順序。文內時間是編輯建議，不是店家開門或供應保證；需趕離島交通時，先倒推報到與移動緩衝。
## 留一晚小金門，把兩天的用餐先排好

[烈嶼住宿比較](/hotels/lieyu/)把西路、雙口、埔頭與上林分開：金典兩館地址不同，雙口的[國境之西](/hotels/#business-guojing-zhixi)與埔頭的[成秀文旅](/hotels/#business-cheng-xiu)也不在同一個聚落。

東林可查[廣豐早餐](/food/#business-guangfeng-breakfast)、[金芋閣](/food/#business-jinyuge)與[沐珈啡](/food/#business-mucafe)；湖下可查[蔡師傅手工麵線](/food/#business-cai-handmade-noodles)。先按餐別與營業時間挑選，不把一份冰品當作全家的晚餐，也不要將烈嶼湖下和本島金寧湖下混淆。
